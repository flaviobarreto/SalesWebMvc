
# SalesWebMvc

![License](https://img.shields.io/badge/license-MIT-blue.svg)
![Platform](https://img.shields.io/badge/platform-.NET%20Core-brightgreen.svg)
![Database](https://img.shields.io/badge/database-SQL%20Server-orange.svg)

SalesWebMvc é um projeto em ASP.NET MVC desenvolvido em C# que utiliza SQL Server como banco de dados. Este sistema gerencia vendedores e suas vendas, com funcionalidades para busca simples e agrupada.

## 🛠️ Tecnologias Utilizadas

- **C#**
- **ASP.NET MVC**
- **Entity Framework Core**
- **SQL Server**
- **Bootstrap** (para estilização)
- **JavaScript** (para interações dinâmicas)

## 🚀 Funcionalidades

- **Cadastro e Gerenciamento de Vendedores**
- **Cadastro e Gerenciamento de Vendas**
- **Pesquisa Simples de Vendas**
- **Pesquisa Agrupada de Vendas**

## ⚙️ Como Executar o Projeto

1. Clone o repositório:
   ```bash
   git clone https://github.com/seu-usuario/SalesWebMvc.git
   ```

2. Abra o projeto no Visual Studio.

3. Configure a string de conexão com o banco de dados SQL Server no arquivo `appsettings.json`.

4. Execute as migrações para criar o banco de dados:
   ```bash
   Update-Database
   ```

5. Execute o projeto:
   ```bash
   dotnet run
   ```
